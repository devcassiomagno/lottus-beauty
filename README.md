# Lottus Beauty — Landing Page

Landing page responsiva desenvolvida para a **Lottus Beauty**, uma marca fictícia de cosméticos capilares inspirada na inovação asiática e no cuidado consciente.

O projeto foi criado como atividade acadêmica, com foco na aplicação prática de HTML5 e CSS3.

## Tecnologias utilizadas

- HTML5 semântico
- CSS3
- CSS Grid e Flexbox
- Variáveis CSS
- Media Queries
- Design responsivo

## Funcionalidades

- Navegação entre seções
- Apresentação institucional da marca
- Galeria de produtos
- Efeitos de hover
- Layout adaptável a diferentes tamanhos de tela

## Acessar o projeto

**Site publicado:** https://cassiomagno7.github.io/lottus-beauty/

## Objetivo

Praticar a estruturação semântica de páginas web, a organização de estilos CSS e a criação de interfaces responsivas, aplicando os conhecimentos adquiridos durante os estudos de desenvolvimento front-end.

## Sobre o projeto

Projeto acadêmico desenvolvido para fins educacionais. A Lottus Beauty é uma marca fictícia.
